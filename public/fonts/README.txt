Put the Ubuntu Sans font files here, named exactly:
  UbuntuSans.ttf          (the variable roman font)
  UbuntuSans-Italic.ttf   (the variable italic font; optional)
  UbuntuSansMono.ttf      (the variable mono font)
Keep the font's licence file here too (for example LICENSE.txt) when you publish the site.
If a file is missing the app falls back to the system font, so nothing breaks.
