Ubuntu Sans (variable, woff2) + Ubuntu Sans Mono, from https://github.com/canonical/Ubuntu-Sans-fonts and
https://github.com/canonical/Ubuntu-Sans-Mono-fonts. Licence: LICENCE.txt (Ubuntu Font Licence), keep it next to the fonts.
  UbuntuSans.woff2          variable roman (weight 100-800)
  UbuntuSans-Italic.woff2   variable italic
  UbuntuSansMono.woff2      variable mono (the "mono" font option)
If a file is missing the app falls back to the system font, so nothing breaks.
